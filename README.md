# Tremulous Revamped (Windows x64)

Download the game from [Releases](https://github.com/MeepingsCorner/Tremulous-Revamped-Release/releases/latest).

1. Download `Tremulous-Revamped-win64.zip` and unzip it anywhere.
2. Run `Tremulous.exe`.
3. Optional 4K textures: download both `tremulous-revamped-hd-textures-part*.zip` files and unzip them into the same folder, so an `hd` folder sits next to `Tremulous.exe`.

Source code: [MeepingsCorner/Tremulous-Revamped](https://github.com/MeepingsCorner/Tremulous-Revamped).
The `base` folder holds the original Tremulous 1.1 content under its own licenses (see `base/COPYING`, `base/CC`).
